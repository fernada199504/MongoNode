# Backend con Node.js y MongoDB

Este proyecto es un backend desarrollado con **Node.js**, **Express** y **MongoDB**.  
Su objetivo es manejar la lógica de negocio y la conexión con la base de datos.

## 🚀 Tecnologías
- Node.js
- Express
- MongoDB (Mongoose)
- Dotenv

## 📂 Estructura de carpetas
backend/
│── node_modules/
│── src/
│ ├── config/ # Configuración (MongoDB, dotenv, etc.)
│ ├── controllers/ # Lógica de negocio
│ ├── models/ # Modelos de MongoDB
│ ├── routes/ # Rutas de la API
│ └── server.js # Archivo principal del servidor
│── .env
│── .gitignore
│── package.json
│── README.md

1. Clonar este repositorio  
   ```bash
   git clone <url-del-repositorio>
 

   2. Instalar dependencias
   npm install

   3. Configurar variables de entorno en el archivo .env

     Levantar el servidor
