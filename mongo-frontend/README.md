# Mongo Frontend

Este proyecto corresponde al **frontend en Angular** para el sistema MongoNode.

---

## 🚀 Requisitos

- Node.js v18 o superior  
- Angular CLI (instalar globalmente si no lo tienes)  
  ```bash
  npm install -g @angular/cli

  ⚙️ Instalación

Clonar el repositorio y entrar en la carpeta del frontend:

git clone https://github.com/fernada199504/MongoNode 
cd MongoNode/mongo-frontend

Instalar dependencias:

npm install

▶️ Ejecución en desarrollo
ng serve
Luego abre en el navegador:
👉 http://localhost:4200

📌 Notas

Asegúrate de que el backend esté corriendo para que el frontend pueda consumir la API.

Backend se encuentra en la carpeta ../backend.
✅ Funcionalidades principales

Registro y autenticación de usuarios (JWT).

Login desde el frontend Angular.

visualizacion de publicaciones 

Conexión a base de datos MongoDB.
📖 Comandos útiles
Backend
npm run dev   # Ejecutar en modo desarrollo con nodemon

Frontend
ng generate component nombre-componente   # Crear un nuevo componente
ng build --configuration production
